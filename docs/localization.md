# 日英対応

## 範囲とUI契約

日本語を既定とし、既存URLを維持する。PortfolioとEngineeringの本文、空状態、仮紹介の注記、メタ情報、支援技術向けの案内を翻訳する。
両ページのヘッダーで日本語 / Englishを選べる。現在の言語を示し、切り替え先は同じ種類のページとする。
ページ内のスクロール位置は引き継がない。戻る操作は通常のブラウザー履歴に従う。

| 内容 | 日本語 | 英語 |
|---|---|---|
| Portfolio | / | /en/ |
| Engineering | /engineering/ | /en/engineering/ |

自動転送、言語の推定、Cookie保存は行わない。追加のクライアントJavaScriptは使わない。
GitHub上の構成文書とADRは日本語のままとし、英語ページにその旨を明記する。コードと製品名は翻訳しない。
デザイン改修は今回の範囲に含めない。

## 設計と責務

`src/lib/i18n.ts`が言語とURL対応を所有する。
PortfolioとEngineeringの表示構造は言語間で共有し、ルートファイルは言語を渡すだけにする。
文言は`src/data/translations.ts`、紹介データは`src/data/portfolio.ts`に日英を揃えて記述する。
レイアウトは文書言語、canonical、hreflangをページの言語と種類から生成する。
ソース対応表は共通表示コンポーネント、文言、紹介データの実体へ向ける。

設計レビュー：Portfolio→同言語Engineering→同言語Portfolio、および各ページでの日英切り替えの往復に矛盾がないことを確認した。
Tab / Enterで選べる通常のリンクを用い、狭い画面ではナビゲーションを折り返す。

## 検証

- 型チェックで翻訳文言のキーの欠落を検出する。
- テストでURL対応と日英の掲載対象の同一性を確認する。
- ビルド時に4ページの文書言語、言語切替、canonical、hreflang、内部リンク、SHA対応を検査する。
- ブラウザーで言語切り替え、Engineering往復、キーボード操作、狭い画面を確認する。
- 200%ズームとスクリーンリーダーは実施状況を別途報告する。
