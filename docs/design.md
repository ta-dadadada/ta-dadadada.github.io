# サイドバー付きの活動一覧

## 選定

ユーザーが比較用プロトタイプ3案からB「サイドバー付きの活動一覧」を選択した。
名前と紹介・案内を左、個人開発と発表資料を右に置く。大きな抽象コピーや装飾用の節番号は使わない。
紹介内容は引き続き仮であり、未確認の経歴・状態・URLは追加しない。

## 表示と操作

- 広い画面は最大1120px、プロフィール列260pxと活動列の2列。
- 背景は青みのあるグレー、活動面は白、リンクと作品名は青。既存のシステムフォントを使う。
- プロフィール側にページ内ナビゲーション、GitHub・Speaker Deck・Engineeringへの導線を置く。
- 活動側はProjects→Talks→Writing。日英切り替えは活動列上部に置き、同じページの別言語へ移る。
- 760px以下ではプロフィール→活動一覧の一列とし、案内と外部リンクを折り返す。情報と導線を隠さない。
- サイドバーの追従固定や開閉操作は設けない。本文スキップリンクは活動一覧へ移動する。
- 公開版のsource / copy / dataリンク、フッターのEngineering導線とSHA表示を維持する。
- Engineeringも同じ配色と文字サイズの基準に揃え、独立ページとして維持する。

## 設計レビュー

主要経路（活動を読む、登壇資料へ進む、言語を切り替える、実装へ進む）と既存のURLを維持する。
既存セクションのアンカーは保持し、プロフィールと外部リンクを左列へ移す。読み順とTab順はDOM順に従う。
幅の狭い画面でも同じ内容に到達できる設計とし、横はみ出し、実操作、支援技術向けの名前は実行時に確認する。

## 検証

テスト・型チェック・4ページの生成物検査に加え、日英のPC幅と狭い画面、本文スキップ、ナビゲーション、言語切替を確認する。
自動アクセシビリティ検査と、未検証の200%ズーム・スクリーンリーダーを区別して報告する。
