# Phase 1: Minimum Portfolio

## 範囲

日本語中心の単一ページ。公開名義はta-dadadada。紹介文は仮と明記し、未確認の経歴・公開URL・実績は補わない。
Engineeringページ、ソース対応リンク、SHA表示、監査はPhase 2以降に扱う。

## UI設計

初めて訪れた人が紹介を読み、Projectsから成果物へ進めることを優先する。
Hero、About、Projects、Writing、Linksを順に配置し、ヘッダーにページ内リンクを設ける。
生成する静的HTMLだけで読める構成とし、外部フォント・画像・スクリプトに依存しない。
温かい白、濃い墨色、深緑を基調にし、大きな見出し・余白・罫線で情報を整理する。
広い画面では節番号と本文を並べ、狭い画面では一列にする。ナビゲーションは折り返し、メニューに隠さない。
リンクは同じタブで遷移し、戻る操作はブラウザーに委ねる。フォームや非同期処理は設けない。
スキップリンク、見えるフォーカス、自然なTab順を提供する。通常文字のコントラストは4.5:1以上を目標とする。
Writingは未掲載の状態を表示する。tenkoはURL未確認のためリンクを作らず、その旨を明記する。

## 設計レビュー

主要経路、空状態、ナビゲーション、狭い画面での読み順、キーボード操作の要件に矛盾がないことを確認した。
架空の記事や無効なリンクは配置しない。デザインレビューは実行時の検証を代替しない。

## 受け入れ確認

- 型チェックと静的ビルドが成功する。
- 主要5セクションがあり、仮の紹介・未掲載の情報を区別できる。

- 広い画面と狭い画面で内容が欠けず、横にはみ出さない。
