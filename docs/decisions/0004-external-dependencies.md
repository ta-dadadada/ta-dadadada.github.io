# ADR-0004: 公開コンテンツを外部サービスに依存させない

## Status
Accepted

## Context
個人サイトの運用負担を抑え、外部サービス停止時にも公開済みの主要内容を閲覧できるようにしたい。
Phase 2ではGitHub上の文書とコードへの導線が必要になる。

## Decision
紹介内容はリポジトリ内で管理し、公開時にも閲覧時にも外部APIから取得しない。
外部フォント・トラッキング・CMSは導入しない。構成文書・ADR・コードの詳細はGitHubへリンクする。
ビルド依存の取得にはnpm、CI・配信にはGitHubを使う。

## Alternatives
- プロフィールや記事一覧を外部APIから取得する：更新を省けるが、停止・認証・形式変更への対応が必要。
- すべての文書をサイト内で描画する：GitHubなしで文書を読めるが、文書表示の仕組みと保守対象が増える。

## Consequences
閲覧時のネットワーク依存を小さくできるが、紹介内容と記事リンクはGitへのコミットで更新する必要がある。
GitHubが利用できない場合はソースやADRの詳細に到達できない。ビルド時には依存パッケージの取得先が必要。
