# ADR-0005: URLで言語を分けて静的生成する

## Status
Accepted

## Context
PortfolioとEngineeringを日本語・英語で提供したい。既存URLと公開版のソース対応を維持し、実行時の依存や保守負担を増やしたくない。

## Decision
日本語は既存のルート、英語は`/en/`配下に置き、共通の表示コンポーネントと型付きの日英文言から4ページを静的生成する。
同じページの言語切替を通常のリンクとして用意する。文書言語、canonical、hreflangを各ページに設定する。
既定は日本語。言語推定・自動転送・Cookie・クライアント翻訳処理は設けない。
GitHub上の設計文書は日本語と明示する。詳細なURLと責務は`docs/localization.md`を参照する。

## Alternatives
- 1ページをブラウザー内で翻訳切り替えする：JavaScriptと言語状態の管理が増え、言語別URLで共有しにくい。
- 言語ごとにページ全体を複製する：最初は簡単だが、構造・導線・ソース参照がずれやすい。
- 翻訳ライブラリを追加する：複数形や多数の言語には有用だが、現在の2言語・2種類の静的ページには不要。

## Consequences
JavaScriptなしで各言語のページを共有でき、既存リンクが保たれる。
本文の更新時は両言語を編集する必要がある。翻訳の自然さと意味の一致は型検証だけでは保証できない。
ページ内のスクロール位置や言語の選択履歴は保存しない。
